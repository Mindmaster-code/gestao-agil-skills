## 3. Utilidade das rotinas

Três métricas, não trinta: primeiro o negócio, depois o time e depois a produtividade (Teoria do Caiaque). Cada uma passa pelo teste.

| Métrica | Pilar (negócio, time ou produtividade) | Número de hoje | Tem dono? | Muda alguma decisão? | Dá para pegar sem operação paralela? |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |

| Aspecto observado | O que você viu na rotina analisada |
|---|---|
| Confiabilidade (compromissos cumpridos contra os previstos) | |
| Fluxo (idade do trabalho parado, espera, tempo entre a entrada e a entrega) | |
| Qualidade (devoluções, retrabalho, falhas depois da entrega) | |
| Decisões (ações vencidas, tempo de espera, decisões reabertas) | |
| Autonomia (problemas resolvidos com critério, menos consultas repetidas) | |
| Pessoas (acordos cumpridos, habilidades que evoluem, colaboração, carga) | |
| Custo da rotina (preparação, participação, manutenção do registro) | |

Se a rotina não produz efeito, investigue antes de aumentar a frequência: a finalidade, a preparação, quem participa e quem decide.
