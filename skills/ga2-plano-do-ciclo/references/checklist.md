# Plano do Ciclo — critério de "bem feito" e erros comuns

## Bem feito

Ciclo
- [ ] Duração fixa e conhecida; a mesma do ciclo anterior.
- [ ] Período com data de início e fim.

Meta
- [ ] Uma meta só, numa frase, com fim visível ("o que fica pronto").
- [ ] Passa nos três testes: mostra pronto na sexta · cabe com folga · alguém fora nota.
- [ ] Ligada a uma iniciativa do OKR ou contramedida do A3 (etiqueta escrita).
- [ ] É a frase que a review vai copiar sem maquiagem.

Capacidade e puxada
- [ ] Capacidade real contada; planejado ~70%.
- [ ] Acréscimo do laboratório: no máximo 3 compromissos por diretor.
- [ ] Quem executa escolheu o que entra; o dono do rumo só apontou prioridade.
- [ ] Todo item veio do Backlog 2D (fatia fina primeiro); nenhum inventado na reunião.
- [ ] Nenhum item maior que uma semana.

Itens
- [ ] Cada item tem dono com nome de pessoa.
- [ ] Cada item tem "pronto é" verificável pelo caminho real (URL, arquivo, log, mensagem).
- [ ] Cada item tem data.
- [ ] Cada item aponta para um cartão do quadro.
- [ ] Itens quebrados em tarefas de um dia ou menos (no quadro).

Rituais e riscos
- [ ] Diária, review e retro marcadas com dia, hora e lugar/canal.
- [ ] Riscos do briefing com resposta e dono.

Registro
- [ ] Arquivo salvo em Plano do Ciclo na pasta do caso (ou `plano-<diretor>.md`).
- [ ] Versão e data registradas; commit quando houver repositório. Ritual que não produziu arquivo não aconteceu.

## Erros comuns (da aula)

| Erro | Sinal | Correção |
|---|---|---|
| Duas metas | "e também…" na frase da meta | escolher uma; a outra vira item ou próximo ciclo |
| Meta-atividade | "trabalhar na campanha" | reescrever como resultado mostrável na sexta |
| Agenda cheia | 100% da capacidade planejada | cortar até 70%; máximo 3 compromissos |
| Cartão de presente | item que o executor não escolheu | o time puxa; o PO prioriza |
| Cartão de área | dono = "Operações" | nome de pessoa |
| Item fora do mapa | "surgiu na reunião" | volta ao Backlog 2D ou espera o próximo ciclo |
| Tarefa de 5 dias | fica a semana toda em "fazendo" | quebrar em tarefas de ≤1 dia |
| "Pronto é" vago | "entregar o relatório" | "relatório salvo no destino combinado, com campos completos e fonte dos números" |
| Ciclo elástico | "esta semana vamos de 2 semanas" | manter o tamanho; calibrar o conteúdo |
| Rituais sem hora | "a gente combina" | dia, hora, lugar no plano |
| Plano só na cabeça | sem arquivo | salvar e registrar a versão |

## Formas de saída

- [ ] Entrega no formato pedido, conforme [entrega-editavel.md](entrega-editavel.md), salva e conferida; nas revisões, mesmo documento e edições humanas preservados.
- [ ] Quando houver fonte Markdown para canvas, âncoras `<!-- c:id -->` intactas; HTML não é cópia obrigatória.
- [ ] Se pediram o canvas: IDs intactos, nenhum `{{` sobrando, campos completos, sem estouro e uma página, conferidos no arquivo entregue.
