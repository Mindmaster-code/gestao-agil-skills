## Feedback na hora (ficha D03, modelo T06) `(adaptação metodológica)`

Em particular, logo depois do fato. Com os quatro passos, leva 3 minutos.

| Passo | Resposta |
|---|---|
| 1. Fato com data: fato observado, com período e contexto | |
| 2. Efeito: impacto sobre entrega, cliente ou colaboração | |
| 3. Pergunta: como a pessoa viu a situação (ouça até o fim) | |
| 4. Combinado: comportamento ou ação combinada | |
| Expectativa previamente conhecida | |
| Apoio do líder e momento de retorno | |

Formulação possível: "Na situação descrita, ocorreu este fato e o impacto foi este. Quero entender a sua perspectiva. Para a próxima situação, precisamos combinar esta mudança e este apoio."
