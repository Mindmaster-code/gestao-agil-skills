# Matriz Esforço × Impacto — checklist de "bem feito" e erros comuns

Fonte: M04 A15, M04 A09, v6 Passo 3 aula 07, editável Mod 2 artefato 07, Ficha artefato 05.

## Bem feito

**Entrada**
- [ ] Só iniciativas na grade; objetivo e KR ficaram fora.
- [ ] Toda iniciativa tem dono e diz qual KR move.
- [ ] A lista inclui o que já roda hoje e as ideias que surgiram na hora (para a matriz cortar).

**Eixos**
- [ ] Régua de impacto escrita: o que é "alto" nesta grade (qual número, quanto).
- [ ] Régua de esforço escrita: unidade (horas, dias de trabalho) e gate humano contado como esforço.
- [ ] Impacto na vertical, esforço na horizontal (padrão desta adaptação, v6).

**Leitura**
- [ ] Cada item tem motivo em uma linha para o impacto e para o esforço.
- [ ] Saiu uma fila numerada, não só quadrantes coloridos.
- [ ] Planeje tem data ou condição de entrada; Encaixe tem "só se não roubar foco".
- [ ] O Evite está registrado com o motivo e ficou fora do backlog.
- [ ] As duas perguntas de fechamento foram respondidas ("o que eu ia fazer antes?" e "tenho coragem de tirar?").
- [ ] Dá para explicar a um terceiro por que cada item espera.

**Saída**
- [ ] A fila virou a linha de cima do Backlog 2D (ou os compromissos do ciclo, no plano de segunda).
- [ ] Item de outra área na mesma grade: desempate levado ao decisor de prioridades, não decidido pelo facilitador.

## Erros comuns

| Erro | Onde a aula fala | Como recusar |
|---|---|---|
| Objetivo ou KR na matriz | v6 07 | "Isso é direção/meta. Só iniciativa entra." |
| Só fazer o Faça já e jogar o resto fora | v6 07 | "A matriz dá sequência. Onde ficam os do Planeje, com data?" |
| Começar pelo item grande e caro | v6 07 (trocar o sistema); Kit (trocar o ERP) | "Quanto ele move em 90 dias? Quanto custa? Cai no Evite." |
| Impacto "alto" por achismo | M04 A15 | "Qual número move e quanto?" |
| Esforço sem unidade | M04 A15 | "Horas? Dias? Tem gate humano?" |
| Esquecer o gate humano no esforço | adaptação: custo da espera por aprovação | "O que espera aprovação custa dias parados. Conta como esforço." |
| Misturar a grade de objetivos (A09) com a de iniciativas (A15) | nota metodológica sobre variantes do Passo 2 | "Objetivo se escolhe antes do OKR, com outra grade." |
| Chamar tarefa de iniciativa | v6 05 | "Tarefa se ordena no backlog. Qual é a aposta?" |
| Matriz sem fila numerada | v6 07 — "você sai com uma fila ordenada" | "Quadrante não é ordem. Numera." |
| Evite sem motivo escrito | M04 A15 (defensável) | "Por que fica fora? Quem pediu? Volta quando?" |

## Formas de saída

- [ ] Formato e destino seguem o pedido ou o documento existente, conforme [Entrega editável](entrega-editavel.md).
- [ ] A entrega foi reaberta e conferida; conteúdo, campos, responsáveis, datas, fontes e edições humanas foram preservados.
- [ ] Se houver Markdown, as âncoras `<!-- c:id -->` estão intactas. Se houver HTML, ele deriva da fonte atual.
- [ ] Se pediram canvas, o modelo correspondente foi usado: IDs intactos, nenhum `{{` residual, sem estouro e uma página quando exigida.
